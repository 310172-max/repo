# 午夜便利商店：首輪地圖底稿

這份底稿記錄目前 Three.js 場景中的實際座標，供碰撞、物品同步和後續遊玩驗收使用。座標原點在商店中央；`x` 左右、`z` 前後，玩家從南側 `z > 0` 進入，朝北側 `z < 0` 撤離。

## 場景尺寸與路線

- 商店內部地面約 **26 × 20 單位**，邊界約為 `x = -13…13`、`z = -10…10`。
- 玩家入口出生點：`(0, 8.2)`；撤離門中心：`(0, -9)`。
- 三排貨架中心線：`x = -4.4、0、4.4`，從約 `z = -5.3` 延伸到 `z = 4.9`。貨架之間形成主要南北通道。
- 收銀檯中心：`(-9.2, 5.2)`；冷藏櫃沿北牆排列，中心 `x = -9、-6.6、6.6、9`。

```text
                              北 / z = -10
 冷藏櫃 (-9,-6.6)       撤離門 (0,-9)       冷藏櫃 (6.6,9)

 方鬍子貓 (-9.4,-5.1)    貨架 x=-4.4 / 0 / 4.4    鍵盤暴走貓 (9.1,-0.5)
        西側區域              南北通道                東側區域

 收銀檯 (-9.2,5.2)       貨架南端                 物品搜尋區
                         入口出生點 (0,8.2)
                              南 / z = +10
```

圖為區域關係示意，非比例施工圖；通道可行走寬度仍需在瀏覽器中驗收。

## 威脅起點

- 方鬍子貓從 `(-9.4, -5.1)` 開始；閒置時玩家進入 6.2 單位內會先收到警告，延遲後追擊。
- 鍵盤暴走貓從 `(9.1, -0.5)` 開始；玩家在 12 單位內衝刺會驚動牠。

## 待遊玩驗收

- 從入口到撤離門是否容易理解，三條貨架通道是否有足夠轉身及搬運空間。
- 西側收銀檯與方鬍子貓的起始位置是否造成難以通過的瓶頸。
- 戰利品是否可見、可達且有合理的風險／價值差異；當前位置只代表程式配置，不代表已驗證平衡。
- 冷藏櫃、貨架與綠色撤離門的亮度對比是否足以在暗場景中導航。
