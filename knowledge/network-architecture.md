# 2 人合作原型的連線架構

## 暫定選擇

- 前端保留 Vite 靜態客戶端，可部署至 GitHub Pages。
- 另外用 Node.js 與 WebSocket 建立小型即時房間服務；第一階段先在本機執行，測 2 名玩家，不先綁定付費託管商。
- 第一位加入者為房主，房主的客戶端負責遊戲模擬並送出狀態快照；第二位玩家送出輸入，服務只把輸入轉給房主，再把房主快照轉播給兩人。
- 房主送出開始訊號後兩邊各自取得滑鼠鎖定；遊戲進行中雙方以約 **10 Hz** 傳送位置／狀態快照。
- 服務暫不保存帳號、戰績或跨回合資料；房間關閉後清除連線狀態。

## 房間規則

- 房主建立隨機短代碼房間；另一位玩家輸入代碼加入。
- 每房最多 2 人。房主離線就關閉房間並中斷隊友連線；隊友離線時房主可留在房間等待重連或結束。
- 遊戲中的位置、物品、分數和怪物狀態由房主決定；來賓客戶端不直接廣播權威狀態。

## 邊界與後續

- 此設計用來快速驗證兩人同步，並非防作弊或可承載公開大量玩家的正式架構。
- WebSocket 服務必須獨立於 GitHub Pages 部署；公開測試前需選定支援持續 WebSocket 的託管環境並使用 TLS，成本和供應商待確認。
- 房主客戶端中斷會結束此原型房間；恢復房主、4 人房間、帳號和持久化資料不在此階段。
